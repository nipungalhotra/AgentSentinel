One gate instead of five prompts.

Every agent has its own way of asking for permission, buried in a different terminal or sidebar. loggdin plugs into each one through its hooks, MCP or a small SDK, and sends every request to the same card. Nothing runs until you answer.

How a request travels.

  1. The agent asks

    Before a risky shell command, file write or network call, the agent's hook hands the request to loggdin over a private local socket. It never leaves your machine.

  2. The card drops

    A card slides out of the MacBook notch, or a floating island on other displays, showing who is asking, the exact command, the folder and the risk. High-risk actions can ask for Touch ID.

  3. You latch a scope

    Press return to allow or esc to deny. The card retracts and keyboard focus goes straight back to your editor or terminal.

Approve exactly as much as you mean.

Once

This command, this time. The default.

10 min

The same command, or the same tool such as git or npm, in this folder for the next 10 minutes.

All folders

The same 10-minute approval in every folder, for when you're working across projects. You opt in each time, and it's never offered for high-risk actions.

Always

Saved as a rule for this folder. Remove it any time from the dashboard.

Deny

The agent is told no and carries on without it.

Approvals stay narrow on purpose. An approved npm test also covers cd web && npm test | head, but not npm test && curl … | sh. A command can't sneak in behind one you've approved.

Questions.

Is it really free?

Yes. Everything in the app today is free during the beta. Paid Pro and Team plans may come later; the waitlist hears about them first, and nothing you use now will be taken away without notice.

Does my code or data leave my machine?

No. Requests travel over 127.0.0.1 and a private Unix socket on your computer. The app has no account and no telemetry. The waitlist form on this site only collects your email address.

Which agents does it work with?

Claude Code, Codex, Cursor, Claude Desktop, Antigravity, GitHub Copilot CLI and zsh. You can also gate your own agents with the Python or Node SDK, or through the MCP server.

Why can't I download the Mac app yet?

macOS blocks apps that aren't signed and notarized by Apple. The signed build is being prepared, and we'd rather wait than ask you to bypass Gatekeeper. You can still build it from source today.

Will it slow my agents down?

Only by the moment it takes you to decide. Everything else is handled locally in milliseconds, and the app uses about 0.1% CPU while idle.

What if loggdin isn't running?

By default agents carry on, so you're never locked out of your own tools. To block everything until loggdin is back, set LOGGDIN_FAIL_CLOSED=1.

Is loggdin affiliated with Anthropic, OpenAI, Google, Cursor or GitHub?

No. loggdin is an independent project. Product names appear only to say what it works with.
